# Port Terminal Handling Invoice Audit

Audit marine terminal handling and service charges using tariff, equipment, cargo, and event evidence.

**Primary buyer:** Ocean shippers, NVOCCs, and cargo owners. **Evidence:** terminal tariffs, bookings, containers, gate moves, lifts, wharfage, security, reefer power, examinations, invoices, and credits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Terminal tariff library
- Booking container registry
- Gate event ingestion
- Lift move validation
- Wharfage calculation
- Security fee audit
- Reefer power duration
- Hazardous cargo fee
- Overweight handling
- Customs exam charge
- Empty return treatment
- Invoice matching
- Terminal dispute workflow
- Credit reconciliation
- Port charge analytics

Run `./start.sh`, then open <http://127.0.0.1:4699>. API: `5699`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
